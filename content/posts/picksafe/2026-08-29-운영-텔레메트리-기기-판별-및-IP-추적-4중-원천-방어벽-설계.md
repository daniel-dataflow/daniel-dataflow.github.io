데이터 기반 의사결정을 지향하는 팀에게 **'로그의 누락'**은 단순한 기술적 결함을 넘어 비즈니스 전략의 왜곡을 초래하는 치명적인 문제입니다. PickSafe의 방문자 분석 시스템을 고도화하면서 겪었던 데이터 휘발 문제와, 이를 해결하기 위해 구축한 **'4중 원천 방어벽(4-Layer Defense)'** 설계 과정을 공유합니다.

---

### 1. 직면했던 기술적 문제 (The Problem)

초기 텔레메트리 시스템을 운영하면서 우리는 다음과 같은 심각한 데이터 정합성 이슈를 마주했습니다.

*   **메타데이터의 파편화**: 이벤트가 발생하는 각 라우터마다 IP/UA를 명시적으로 전달하는 구조였기에, 신규 라우터 개발 시 데이터 누락이 빈번하게 발생했습니다.
*   **인앱 웹뷰의 복잡성**: 15종이 넘는 모바일 인앱 브라우저(카카오톡, 네이버, 인스타그램 등)가 표준 User-Agent 패턴을 벗어나 기기 판별 오류가 잦았습니다.
*   **세션 발급의 모호성**: PWA나 브라우저 캐시로 인해 세션이 중복 처리되거나, 반대로 누락되는 '세션 침묵' 현상이 발생했습니다.
*   **관리자 데이터 오염**: 관리자가 모바일 LTE 환경에서 어드민 페이지에 접속할 때, 시스템이 이를 '관리자 IP'로 자동 등록하여 일반 모바일 트래픽까지 통계에서 배제되는 오류가 발생했습니다.

---

### 2. 기술적 고민과 Trade-off (Engineering Decisions)

이 문제를 해결하기 위해 시스템의 내구성을 높이는 방향으로 아키텍처를 전면 재설계했습니다.

#### ① 세션 메타데이터 자동 상속 엔진 (Session Inheritance)
**고민:** 모든 라우터 함수에 IP/UA를 강제로 인자로 전달하게 할 것인가?
**결정:** 개발자의 휴먼 에러를 방지하기 위해 **'백엔드 자동 상속'** 방식을 택했습니다. 만약 특정 라우터에서 메타데이터를 누락하더라도, 데이터베이스 내 동일한 `session_id`를 가진 가장 최근 기록을 조회해 IP와 기기 정보를 자동으로 채워 넣도록 `log_analytics_event` 로직을 개선했습니다. 
*   **Trade-off**: DB 쿼리 부하가 소폭 증가하지만, 데이터 무결성 보장이 비즈니스 측면에서 훨씬 가치 있다고 판단했습니다.

#### ② 15종 인앱 웹뷰 정밀 파서
**고민:** 외부 라이브러리를 사용할 것인가, 직접 관리할 것인가?
**결정:** 범용 라이브러리는 최신 인앱 환경 대응이 늦는 경우가 많았습니다. 유지보수 부담을 감수하고, 운영 환경에서 수집되는 UA 문자열 기반의 자체 파서(`analytics_service.py`)를 직접 구현하여 100%에 가까운 판별 정확도를 확보했습니다.

#### ③ 관리자 인증 토큰 검증 강화
**고민:** IP 기반 차단인가, 인증 토큰 기반 차단인가?
**결정:** 동적 IP 환경(LTE/5G)에서 IP 기반 차단은 무용지물입니다. **`admin_access_token` 쿠키 유무**를 인증의 핵심 지표로 삼아, 관리자가 실제 로그인된 상태에서만 집계에서 제외되도록 로직을 수정했습니다.

---

### 3. 엔지니어링 교훈 (Takeaways)

이번 프로젝트를 통해 얻은 가장 큰 배움은 **"방어적 설계는 선택이 아닌 필수"**라는 점입니다.

1.  **클라이언트 사이드는 항상 신뢰할 수 없다**: 브라우저 캐시나 PWA 상태에 의존하지 않고, 당일 최초 접속 시 프론트엔드에서 강제 핑(Ping)을 날리는 '2중 안전망'을 구축함으로써 세션 집계의 누락을 완전히 방어했습니다.
2.  **데이터 무결성은 로직의 우아함보다 중요하다**: 다소 복잡해 보이더라도 DB 자동 상속과 같은 보수적인 방어 기제를 도입함으로써, 이후 추가되는 어떤 라우터에서도 데이터 누락 가능성을 제로로 만들 수 있었습니다.
3.  **UI/UX도 데이터 분석의 일부다**: 모바일 뷰포트에서 테이블이 깨지는 현상은 사용자 경험뿐만 아니라 관리자의 대시보드 해석력을 떨어뜨립니다. `min-width`와 `touch-scroll`을 적용한 반응형 테이블 설계는 데이터 가독성을 유지하는 데 필수적인 요소였습니다.

---

### 결론

현재 PickSafe의 텔레메트리 시스템은 `Unknown` 기기 발생률 0%, 메타데이터 누락 0%를 기록하고 있습니다. 이번 개선으로 확보한 정확한 데이터는 향후 더 정밀한 사용자 행동 분석과 마케팅 최적화의 밑거름이 될 것입니다.

시스템 설계는 결국 **'예외 상황을 어떻게 통제할 것인가'**의 싸움입니다. 이번 4중 방어벽 구축이 유사한 고민을 가진 엔지니어분들에게 작은 이정표가 되기를 바랍니다.
