안녕하세요, PickSafe 백엔드/아키텍처 담당 에디터입니다. 
서비스의 글로벌 유저가 빠르게 늘어나면서, 성분 매칭 제보나 앱 버그 신고 같은 1:1 고객 문의(Inquiry) 양도 폭발적으로 증가했습니다. 

이번 포스팅에서는 **급증하는 다국어 고객 문의를 해결하기 위해 단일 모놀리식 어드민 코드를 도메인별로 분리하고, 대시보드에 실시간 AI 번역 엔진을 도입한 과정**을 공유합니다. 어떤 기술적 문제를 마주했고, 왜 이러한 아키텍처를 선택했으며, 어떤 성과를 거두었는지 정리해 보았습니다.

---

## 1. Problem: 글로벌 서비스 전환기의 병목 현상

서비스가 글로벌로 확장됨에 따라 영어, 일본어, 중국어 등 다양한 언어의 1:1 문의가 유입되기 시작했습니다. 하지만 기존 시스템은 다음과 같은 한계에 부딪혔습니다.

1. **운영 효율성 저하 (Human Bottleneck)**
   * 관리자가 외국어 문의를 확인하기 위해 외부 번역기를 일일이 복사/붙여넣기 해야 했습니다.
   * 한국어로 작성한 답변을 다시 고객의 모국어로 번역해 전달하는 과정에서 **평균 응답 시간(Response Time)이 15분 이상** 소요되었습니다.
2. **비대해진 모놀리식 어드민 코드베이스**
   * 초기 속도 유지를 위해 단일 파일(`admin.py`)에 집중시켰던 라우터와 관련 템플릿 로직이 거대해졌습니다.
   * 새로운 기능을 하나 추가할 때마다 사이드 이펙트(Side Effect) 예측이 어려워지고 유지보수 생산성이 급격히 떨어졌습니다.

---

## 2. Technical Challenge & Solution

이 문제를 해결하기 위해 **1) 어드민 모듈의 도메인별 완전 분할**과 **2) LLM 기반 실시간 양방향 다국어 번역 시스템**을 동시에 설계하고 적용했습니다.

```
┌─────────────────────────────────────────────────────────────┐
│ 1. 어드민 아키텍처 도메인별 완전 모듈 분할                  │
│    - routers/admin/ (translations, inquiries, users 등)      │
│    - 프론트엔드 static/js/admin/ 및 templates/admin/ 완전 분리│
└─────────────────────────────────────────────────────────────┘
                              │
┌─────────────────────────────────────────────────────────────┐
│ 2. 1:1 고객문의 실시간 양방향 다국어 AI 번역 엔진           │
│    - [수신] 외국어 원문 ↔ 한국어 즉시 토글 번역               │
│    - [발신] 한국어 답변 작성 ➔ 고객 언어 자동 감지 및 변환  │
│    - 자주 쓰는 답변 템플릿(Quick Replies 3종) 원클릭 삽입   │
└─────────────────────────────────────────────────────────────┘
```

### 2.1. 어드민 모듈 분할 (Decoupled Admin Modules)
* **기존 방식:** 하나의 거대한 `admin.py` 라우터 파일에서 모든 권한 관리, 유저 조회, 문의 처리를 담당.
* **개선 방식:** FastAPI의 라우터 분할 패턴을 적극 활용하여 도메인별 전용 모듈(`translations.py`, `inquiries.py`, `visitors.py`, `settings.py` 등)로 분리했습니다.
* 프론트엔드 역시 기능별 전용 템플릿(`templates/admin/`)과 정적 파일(`static/js/admin/`)로 나누어 관심사를 완전히 분리(Separation of Concerns)하고 코드 가독성을 극대화했습니다.

### 2.2. 실시간 다국어 AI 양방향 번역 엔진 연동
* **수신(Inbound) 번역:** 대시보드 내에서 고객이 접수한 외국어 원문을 단 한 번의 클릭으로 한국어로 즉시 토글해서 볼 수 있도록 구현했습니다.
* **발신(Outbound) 번역:** 관리자가 한국어로 편하게 답변을 작성한 뒤 `고객 언어로 답변 변환` 버튼을 누르면, Gemini Pro API가 고객의 모국어 및 서비스 톤앤매너에 맞게 정중한 표현으로 자동 변환하도록 파이프라인을 구축했습니다.
* **생산성 극대화:** 운영진이 자주 사용하는 답변 템플릿(Quick Replies 3종)을 원클릭으로 삽입할 수 있는 기능도 함께 추가하여 반복 업무를 최소화했습니다.

## 3. Results & Takeaway

이번 아키텍처 개선과 AI 기능 도입을 통해 다음과 같은 정량적/정성적 성과를 거둘 수 있었습니다.

* **응답 시간 80% 이상 단축:** 기존 평균 15분이 소요되던 글로벌 고객 문의 응대 시간이 **3분 이내**로 대폭 단축되었습니다.
* **코드 유지보수성 확보:** 거대 모놀리스였던 어드민 라우터를 도메인 단위로 깔끔하게 분리함으로써, 향후 기능 확장 시 발생할 기술 부채를 미연에 방지했습니다.

### 💡 엔지니어링 교훈 (Takeaways)
1. **비즈니스 성장 속도에 맞춘 아키텍처 진화:** 초기 스타트업 단계에서 빠른 개발을 위해 모놀리식 구조를 택하는 것은 합리적이지만, 특정 도메인(예: 어드민, 고객지원)의 트래픽이나 복잡도가 임계점을 넘을 때는 과감하게 모듈러 모놀리스(Modular Monolith) 형태로 전환하는 타이밍이 중요합니다.
2. **AI의 실무 적용(LLM Integration):** LLM은 단순히 챗봇이나 생성형 콘텐츠 제작뿐만 아니라, **운영 에디터들의 단순 반복 노동(번역, 템플릿화)을 혁신적으로 줄여주는 실무형 자동화 도구**로 활용했을 때 비즈니스 임팩트가 가장 크다는 것을 확인했습니다.

앞으로도 PickSafe는 기술적 완성도와 사용자(및 운영자) 경험을 모두 만족시키는 방향으로 시스템을 고도화해 나갈 것입니다. 감사합니다.
