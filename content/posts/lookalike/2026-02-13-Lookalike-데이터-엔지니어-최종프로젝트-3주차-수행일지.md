### 🔹 \[이주형\] - \[팀원/Data Science\]

💡 **Keep (유지할 것)**

*   **전략적 모델 믹스(Model Mix):** 고성능 API(Gemini 1.5 Flash)를 활용해 최적의 프롬프트와 결과물 가이드를 먼저 확보하고, 이를 경량 모델(On-premise VLM)로 전이하는 효율적인 R&D 프로세스 유지
*   **추적 가능성(Observability):** API 호출 이력 및 파싱 로그를 기록하여 데이터 유실 지점을 빠르게 파악할 수 있는 디버깅 환경 관리

🔍 **Problem (문제점)**

*   **VLM 응답의 비일관성(Parsing Failure):** 모델이 JSON 포맷 외에 불필요한 서문/설명을 포함하거나 형식을 위반하여 발생하는 데이터 파싱 에러 및 유실 문제
*   **처리 확장성(Scalability) 한계:** 대량 데이터 처리 시 외부 API의 비용 부담과 초당 호출 수(RPM) 제한으로 인한 전체 파이프라인 속도 저하

✨ **Try (시도할 것)**

*   **데이터 추출 가드레일 구축:** Pydantic 기반의 스키마 검증 또는 Regex 후처리 로직을 도입하여 VLM 응답에서 순수 JSON 데이터만 추출하는 안정성 강화
*   **하이브리드 검색 엔진 고도화:** 시각적 유사도와 텍스트 의미 유사도를 결합하는 **Late Fusion** 로직을 실험하고, 이를 ElasticSearch 기반 쿼리에 반영하여 검색 정확도 개선

### 🔹 \[정수아\] - \[팀원/Data Science\]

**💡 Keep (유지할 것)**

*   **Mac–Linux 환경 구축 및 컨테이너 생성** : 실행 환경 일관성을 위해 Linux 기반 이미지 생성 후 Docker 컨테이너 구성
    
*   **Airflow 이미지 처리 모델 프로세스**
    
    : 이미지 수집부터 모델 추론, 저장까지 자동화된 처리 파이프라인 구축 진행
    

**🔍 Problem (문제점)**

*   **Mac ARM 기반 Linux 환경 구성의 어려움**
    
    : ARM 아키텍처와 기존 x86 환경(AMD) 간 호환성 문제로 Docker 기반 Linux 환경 구성에 어려움 발생
    
    *   일부 이미지가 ARM을 지원하지 않아 대체 방법 및 추가 설정 필요
    *   멀티 아키 컨테이너 환경 구성 과정에서 Kafka 컨테이너가 정상적으로 올라오지 않고 반복적으로 재시작되는 문제가 발생하여 서비스 간 의존성 및 설정 재검토

**✨ Try (시도할 것)**

*   Airflow 기반 모델 추론 자동화 파이프라인 설계
*   검색 품질 향상을 위한 모델 성능 개선 전략 수립 및 적용
