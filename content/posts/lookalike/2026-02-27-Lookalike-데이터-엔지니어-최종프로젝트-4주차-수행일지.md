### 🔹 \[이주형\] - \[팀원/Data Science\]

💡 **Keep (유지할 것)**

*   **워크플로우 자동화(Workflow Automation):** 개별적으로 동작하던 이미지 분석, 번역(GoogleTranslator), JSON 파싱 스크립트를 Airflow 기반의 데이터 파이프라인으로 통합하여 자동화
*   **도메인 특화 프롬프트 튜닝:** 로컬 LLM(Ollama, Huggingface 등)을 활용해 패션 도메인에 맞게 옷의 외형적 설명, 핏(Fit), 실루엣, 소재감 등의 디테일을 깊이 있게 추출하도록 프롬프트를 지속적으로 개선한 점
*   **유연한 데이터 전처리 구조:** 폴더 경로를 브랜드별로 순회할 수 있도록 구조화하여, 대량의 이미지를 확장성 있게 배치(Batch) 처리할 수 있는 환경 유지

🔍 **Problem (문제점)**

*   **Airflow 통합 과정의 런타임 에러:** 기존에 독립적으로 실행되던 Python 스크립트들을 Airflow의 DAG 및 Task로 엮는 과정에서 발생한 경로 인식 오류, 환경 변수 문제, 패키지 의존성 충돌 등의 통합 이슈
*   **배치 처리 중단 리스크:** 폴더별로 수많은 이미지를 로컬 모델로 추론할 때, 간헐적인 모델 응답 지연이나 예기치 않은 출력 포맷(JSON 파싱 에러)으로 인해 전체 파이프라인 Task가 멈추거나 재시작해야 하는 안정성 문제

✨ **Try (시도할 것)**

*   **Airflow DAG 안정성 및 예외 처리 강화:** Task 실패 시 자동으로 재시도(Retry)하는 로직을 추가하고, 에러 발생 시 어느 브랜드의 어떤 이미지에서 멈췄는지 즉각적으로 파악할 수 있도록 로깅(Logging) 및 알람 세분화
*   **파이프라인 데이터 검증 단계 추가:** 추출된 JSON 데이터(외형, 디테일, 번역 결과 등)가 DB나 검색 엔진(ElasticSearch)에 적재되기 전, 필수 키값(summary, description, details 등)이 누락되지 않았는지 Airflow Task 내에서 자동으로 검수하는 품질 체크(Data Quality Check) 로직 도입

### 🔹 \[정수아\] - \[팀원/Data Science\]

**💡 Keep (유지할 것)**

*   **이미지 처리 모델 자동화 파이프라인 구축**
    
    : Hadoop에 저장된 이미지를 불러와 객체탐지 → 분류 → 임베딩 추출 → DB 저장까지 이어지는 자동화 파이프라인 구현 및 Airflow 태스크 수정(저장 방식, DB 저장)
    
*   **검색 로직 분석 및 FastAPI 구현**
    
    : 실제 서비스에서 사용되는 검색 로직을 분석하고 FastAPI 기반 검색 API로 구현
    
*   **벡엔드 코드 통합 작업**
    
    : 구현한 검색 API를 기존 백엔드 코드와 통합하고 로직이 적용되어 구현되는지 테스트 진행
    

**🔍 Problem (문제점)**

*   **조인 키 정합성 이슈**
    
    : 검색 로직 구현 과정에서 테이블 간 기준 키 타입 및 포맷 불일치로 데이터 매핑 오류가 발생하여 예외처리로 들어간 fallback 데이터를 가져오는 문제 → 키 정규화 및 스키마 정비 후 해결
    
*   **Docker 환경 이슈**
    
    : 검색 로직 구현 과정에서 볼륨 충돌 및 디스크 용량 부족 문제로 인해, 임베딩 모델이 정상적으로 로드되지 않는 실행 오류 발생 → 불필요 볼륨 정리 및 리소스 확보 후 정상화
    
*   **검색 품질 저하 이슈**
    
    : DB에 적재된 샘플 데이터 수의 부족으로 검색 성능 검증에 한계 존재, VLM 기반 생성 텍스트가 SBERT의 임베딩 목적에 최적화되지 않아 재추론 및 프롬프트 개선 필요
    

**✨ Try (시도할 것)**

*   **데이터 적재량 확대 및 재검증**
    
    : 추가 데이터 수집 및 DB 적재 후 검색 성능 재테스트 및 정량적 성능 검증 진행
    
*   **VLM 프롬프트 엔지니어링 개선**
    
    : 생성 텍스트 품질 향상을 위한 프롬프트 구조 개선 및 출력 포맷 정제 실험 진행
    
*   **검색 로직 보완**
    
    : 텍스트 검색 단계에서 Rewrite 기법 적용 - LLM을 활용해 텍스트를 정제한 뒤 임베딩하는 로직으로 재구성
    
*   **API 구조 리팩토링 및 코드 정리**
